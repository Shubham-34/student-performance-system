# STUDENT PERFORMANCE SYSTEM (Website)

## EASIEST WAY TO RUN

1. **Extract the ZIP file first** (right-click → Extract All). Do not open files directly inside the ZIP.
2. Double-click `START.bat` in the extracted folder. The website will open in your browser.

   Alternatively, double-click `Student_Performance_System_ONE_FILE.html`.

## WHAT'S INSIDE THE FOLDER

- `START.bat` — Double-click this file to launch the website.
- `Student_Performance_System_ONE_FILE.html` — The entire website in a single file. It works independently.
- `index.html` + `style.css` + `script.js` — The same website split into three separate files. All three files must remain in the same folder.
- `README.txt` — This instruction file.

## IMPORTANT NOTES

- Never double-click `script.js`. Windows handles JavaScript files differently, which may cause errors.
- Always open `index.html` or `Student_Performance_System_ONE_FILE.html`.
- If a file opens in a text editor (VS Code or Notepad), it is showing the source code, not the website. Right-click the HTML file and select **Open with → Chrome** (or another web browser).
- Opening files directly inside a ZIP archive may prevent the design and code from loading properly. Extract the files first.
- Extracting ZIP files on a phone can be difficult. In that case, use the live webpage link.

## USING VS CODE

1. Open the extracted folder using **File → Open Folder**.
2. Install the **Live Server** extension.
3. Right-click `index.html` and select **Open with Live Server**.

## FIRST TIME USING THE WEBSITE

- The website initially displays 7 sample students.
- Click **Clear Sample Data** to remove the sample records and enter your own data.
- Your data is saved in your browser, so it remains available in the same browser on the same computer.

## CUSTOMIZATION

- To change the subjects, edit the `SUBJECTS` list near the top of `script.js`.
- To change rules such as passing marks and attendance requirements, edit the **Rules and Grading** section near the bottom of the page.
