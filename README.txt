STUDENT PERFORMANCE SYSTEM (Website)
====================================

SABSE EASY TAREEKA
------------------
1. Zip ko pehle EXTRACT karo (right click > Extract All). Zip ke andar se mat kholo.
2. Folder me "START.bat" par double-click karo. Website browser me khul jayegi.
   (Ya "Student_Performance_System_ONE_FILE.html" par double-click karo.)

Folder me kya hai
-----------------
START.bat                              <- double-click, website khul jayegi
Student_Performance_System_ONE_FILE.html  <- poori website ek hi file me (ye akeli bhi chalti hai)
index.html + style.css + script.js     <- wahi website, 3 alag files me
                                          (teeno ek hi folder me rehni chahiye)
README.txt                             <- ye file

ZAROORI BAATEIN
---------------
* script.js par kabhi double-click mat karo. Windows use alag tarah se chalata hai aur error dega.
  Hamesha index.html ya ONE_FILE.html kholo.
* File kisi editor (VS Code / Notepad) me khul jaye to wo website nahi hai, text hai.
  File par right click > Open with > Chrome (ya Edge).
* Zip ke andar se seedha kholne par design aur code load nahi hote. Pehle Extract karo.
* Phone par zip extract karna mushkil hota hai. Wahan live page ka link use karo.

VS CODE ME
----------
Folder kholo (File > Open Folder), Live Server extension install karo,
index.html par right click > Open with Live Server.

PEHLI BAAR
----------
7 sample students dikhenge. "Clear sample data" dabake apna data daalo.
Data aapke browser me save hota hai (usi browser, usi computer par).

Subjects badalne ho to script.js ke upar SUBJECTS list me edit karo.
Rules (passing marks, attendance) page ke neeche "Rules and grading" me badalte hain.
